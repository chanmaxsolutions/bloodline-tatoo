# COMPONENT_BLUEPRINTS.md

# Bloodline Tattoo Platform — Component Blueprints

This document defines the official section architecture, page anatomy, reusable component structures, conversion rhythm, and composition rules for the Bloodline Tattoo platform.

The purpose of this document is to ensure:

- structural consistency
- scalable page generation
- reusable composition systems
- SEO-safe layouts
- conversion-focused sequencing
- predictable AI-assisted implementation

All pages and sections must follow these blueprints unless a strong architectural reason exists to deviate.

---

# 1. Core Composition Philosophy

Every page should follow this psychological rhythm:

```txt
Attention
→ Trust
→ Proof
→ Depth
→ Conversion
```

This structure exists because tattoo businesses are:

- emotional
- trust-heavy
- proof-driven
- visually evaluated
- high-intent

The user should continuously move toward increased confidence.

---

# 2. Section Categories

The platform uses six primary section categories.

Hero Sections

Each section type has a clear responsibility.

# 5. Hero Rules

Required:

- uppercase heading
- strong regional keyword presence
- dark cinematic media
- WhatsApp-first CTA
- immediate trust reinforcement

Preferred:
- large typography
- controlled overlay gradients
- aggressive composition
- visual proof support

Avoid:
- long paragraphs
- weak CTA positioning
- decorative filler content
